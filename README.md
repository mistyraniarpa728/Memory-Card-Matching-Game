## 🌟 About The Game

Memory Card Matching Game is a fun and colourful 2D puzzle game designed to improve memory and concentration.

Players flip two cards at a time and try to find identical pairs. The objective is to match all cards before the countdown timer reaches zero.

## ✨ Game Features

### 🎯 Essential Features
- 🏠 Start Menu
- 🃏 Card Matching System
- 🔄 Interactive Card Flip
- ⭐ Score System
- ⏱️ Countdown Timer
- 🔢 Move Counter

### 🚀 Core Upgrade Features
- 🎚️ Three Difficulty Levels
- 🏆 Win & Game Over Screen
- 🔁 Restart Game
- 🏠 Return to Home Menu

### 💡 Optional Features
- 🔊 Sound Effects
- ⏸️ Pause / Resume
- 💡 Hint System
- 🥇 Best Score Saving

## 🎯 Difficulty Levels

| Level | Card Grid | Matching Pairs | Time Limit |
|:---:|:---:|:---:|:---:|
| 🟢 Easy | 4 × 4 | 8 | 120 Seconds |
| 🟡 Medium | 4 × 5 | 10 | 100 Seconds |
| 🔴 Hard | 6 × 6 | 18 | 90 Seconds |

## ⚙️ Installation & Setup

### 1. Clone the Repository

```bash
git clone https://github.com/mistyraniarpa728/Memory-Card-Matching-Game.git
```

### 2. Open Project Folder

```bash
cd Memory-Card-Matching-Game
```

### 3. Install Dependencies

```bash
pip install pygame-ce
```

### 4. Run the Game

```bash
python main.py
```
